# Своё дело

Геймификация пути от нуля клиентов к деньгам для человека, который умеет делать
сайты на Tilda и квизы на Marquiz, но ещё ни разу не продавал.

Статическая страница без сборки и без сервера: прогресс живёт в браузере,
страница ставится на домашний экран телефона и работает без интернета.

## Зачем

Обычный финансовый трекер отвечает на вопрос «сколько у меня денег». Этот отвечает
на другой: **что сделать сегодня, чтобы деньги появились.**

Цепочка считается в обратную сторону и пересчитывается сама:

```
цели в рублях ÷ свои сроки  →  сколько нужно в месяц
      ÷ средний чек         →  сколько заказов в месяц
      ÷ конверсия           →  сколько касаний в месяц
      ÷ рабочие дни         →  НОРМА КАСАНИЙ НА СЕГОДНЯ
```

На дефолтных целях (переезд, аренда, подписка, подарок) это выходит десять касаний
в день при чеке 300 р. и шесть — при чеке 500. Второй вывод приложение показывает
специально: поднять цену дешевле, чем писать вдвое большему числу людей.

Если цели требуют невозможного, приложение так и пишет: «столько не бывает» —
и считает, какой чек исправил бы дело. Врать в сторону оптимизма оно не умеет.

## Как это устроено

| Слой | Что даёт | Как часто |
|---|---|---|
| Норма касаний | день не закрывается, пока не сделана | каждый день |
| Касание в один тап | человек попадает в воронку одним полем | десятки раз в неделю |
| Воронка | нашла → написала → ответил → обсуждаем → счёт → оплатил | постоянно |
| Квота отказов | двадцать «нет» как отдельная цель с XP | фон |
| Остыли | кто три дня молчит — сам всплывает с кнопкой «напомнила» | каждый день |
| Заказы | этапы работы как полоса, сдача и оплата в кассу | в работе |
| Прайс-лестница | после двух оплаченных заказов предлагает поднять цену | раз в месяц-два |
| Цели и касса | приход сам раскидывается по целям, ближняя дата первой | по приходу |
| Вехи | четырнадцать разовых событий от портфолио до первого клиента | редко |
| Навыки | жетоны → Tilda, Marquiz, продажи, поток | раз в неделю-две |
| Лавка | жетоны → награды, за которые платит он | по желанию |

### Почему награда за отказ

При нуле клиентов результат не контролируется, а действие — контролируется.
Поэтому XP даётся за касание и за отказ, а не за оплату: иначе первые три недели
приносят ноль обратной связи, и человек бросает ровно там, где начинается работа.
Квота в двадцать «нет» переворачивает страх: отказ становится прогрессом.

### Почему день не закрывается без нормы

Серия — самое дорогое, что есть в приложении, и она упирается только в касания.
Дела, учёба и портфолио не спасают: можно сделать всё остальное и не закрыть день.
На больные дни есть откуп за жетон, два раза в месяц, и выходные без нормы.

## Деплой

[vercel.com/new](https://vercel.com/new) → импортировать репозиторий → **Deploy**.
Настраивать нечего: сборки нет, переменных окружения нет, всё лежит в корне.
Дальше каждый push раскатывается сам.

Или из терминала, без GitHub: `npx vercel --prod`.

## На телефон

Открыть адрес в браузере → «Поделиться» → **На экран «Домой»**. Запустится без
адресной строки, как обычное приложение.

Открывать лучше именно с домашнего экрана: у установленного приложения своё хранилище,
которое браузер не чистит вместе с обычными вкладками.

## Где лежат данные

Только в браузере, ключ `delo-v1`. Аккаунта нет, никуда ничего не отправляется.
При первом запуске приложение просит у браузера постоянное хранилище
(`navigator.storage.persist`) — без этого Safari вычищает данные сайта после недели
без визитов.

Бэкап — на вкладке **РОСТ → итоги**: файлом или строкой, восстановление принимает оба
формата. Если бэкапа не было больше месяца, на вкладке **СЕГОДНЯ** появится напоминание.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | разметка |
| `styles.css` | токены светлой и тёмной темы, компоненты |
| `fonts.css`, `fonts/` | Oswald, Manrope, IBM Plex Mono — лежат рядом, наружу приложение не ходит |
| `data.js` | воронка, прайс, вехи, навыки, состояние и обратный счёт `plan()` |
| `render.js` | отрисовка всех экранов |
| `app.js` | действия, серия, крутилка, касса, бэкап |
| `sw.js` | офлайн-кэш |
| `manifest.webmanifest`, `icon.svg`, `icon-*.png` | имя и иконка на домашнем экране |
| `vercel.json` | заголовки |

Правишь любой файл приложения — подними версию `V` в первых строках `sw.js`.
